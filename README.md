# Trickster-Recipe-Checker

## Details
Authored By: Kelsey White
Last Updated: July 30th, 2026

## Description
Developed for X Trickster Online. Chrome web extension that checks a user's inventory/web bank on xtrickster.com to determine how many recipes can be created from the ingredients in the user's storage. 

## How To Use This Extension
Install the extension from the Chrome Web Store to your Google Chrome Browser.

Log in to xtrickster.com and navigate to the account panel. Select 'Web Bank' and select the user you would like to check inventory.

You may have the recipe ingredients in either that user's web storage or inventory. To use either, the respective tab must be open on the page for the selected character.

Open your extensions and select 'Recipe Checker'. Click the 'Check Recipes' button to process the items in storage. The recipes that can be created will then be displayed within the extension interface.

## Privacy Policy
### Recipe Checker for Trickster Online

Recipe Checker processes inventory information displayed on the supported inventory webpage in order to determine which recipes can be crafted.

- No personal information is collected.
- No inventory data is transmitted to external servers.
- No user data is sold or shared with third parties.
- All processing is performed locally within the user's browser.
- The extension does not use analytics, advertising, tracking technologies, or remote code.
